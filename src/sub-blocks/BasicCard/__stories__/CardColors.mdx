# Card color themes

These CSS tokens are shared by BasicCard, BackgroundCard, ImageCard, MediaCard,
PriceCard, PriceDetailed and Quote. The stories below use BasicCard to compare
`shadow`, `line` and `none` borders.

Site developers set tokens once on the site theme. Cards inherit them, and a nested
section can override them for all its cards. Light and dark themes can use different
values. These are theme settings, not per-card fields in the content editor.

- Without overrides, cards keep their existing appearance.
- `border="none"` removes the border and shadow, but keeps the fill. Set the background
  token to `transparent` explicitly to remove the fill.
- Hover colors apply to cards with a `url` set.
- An individually configured card background keeps its priority.
- Inherited hover and outlined tokens take priority over a local general background.
  Override those tokens too when changing a section theme.
